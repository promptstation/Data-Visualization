# Domain Content Map — 3D Data Representation: Honest Encoding of Multidimensional Data in Space

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module
development workflow. Verify all factual claims and numbers against the
authoritative sources before publishing (Phase 2 evidence base); flag
anything disputed rather than repeating it.

## Absorbed capabilities this module must produce
1. Apply the 3D-honesty framework (depth-ambiguity, foreshortening, occlusion distortion evidence.
2. Tufte lie-factor doctrine.
3. Justification-burden test) categorizing legitimate 3D uses (spatial-native, structure, immersive, exploration-aid).
4. Build 3D scatters with legibility systems (axis triads, projection shadows, rotation interaction, hull-peel occlusion management) under exploration-not-estimation positioning, render surfaces and volumes with vertical-exaggeration disclosure.
5. Manage extrusion comparisons through orthographic cameras and baseline visibility with when-2D-wins analysis.
6. Construct 3D networks with task-fit hairball assessment, engineer depth cues deliberately, resolve lighting-color encoding conflicts via emissive materials, compose 2D-3D hybrids (linked views.
7. Map-extrusions, progressive disclosure), and pass 3D design reviews through accuracy audits, task validation, load assessment, and accessibility review.
