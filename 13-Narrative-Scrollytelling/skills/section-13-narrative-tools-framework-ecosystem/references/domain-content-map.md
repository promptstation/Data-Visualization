## Absorbed capabilities this module must produce
1. Navigate the scrollytelling stack through scroll library mastery (Scrollama minimal philosophy with API and framework ecosystem, GSAP ScrollTrigger capabilities with licensing awareness, framework-native options across React-Svelte-Vue-Astro, no-code tier with limits judgment, selection framework matching capability-team-longevity-cost).
2. Integrate visualization libraries (D3 as rendering engine with transition synchronization and framework composition, higher-level charting options with narrative limitation assessment.
3. Map story tooling with performance management, canvas-WebGL escalation with hybrid architectures, data-complexity-to-renderer selection logic).
4. Build production stacks (CMS integration with structured content models and MDX patterns, SSG-build-asset-deployment pipelines, reusable component and template systems with design system integration, collaboration tooling from storyboards through deploy previews, stack selection by volume-autonomy-longevity), track emerging frontiers (AI-assisted production with verification obligations, scroll-driven CSS and view transitions platform evolution, immersive-audio-video formats, ecosystem monitoring with adopt-trial-assess discipline, future-proofing through dependency minimization and archival planning), and avoid framework-first, library bloat, no-code collisions, D3 monoliths, CMS afterthoughts, dependency risk, unverified AI code, and archive neglect failures.
