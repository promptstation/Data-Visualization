## Absorbed capabilities this module must produce
1. Engineer scroll experience performance through stakes grounding (jank-narrative connection with abandonment consequences, frame-load-payload budget frameworks with documentation, scrollytelling performance profiles, mobile majority reality).
2. Optimize loading (critical rendering path with first screen priority, asset compression and code splitting, progressive skeleton-prefetch-degradation architecture, Lighthouse and RUM measurement, caching strategies), enforce runtime frame discipline (scroll handler optimization with observer preference and layout thrash prevention, compositor-only animation with layer management, SVG budgets with canvas escalation and viewport culling, memory lifecycle management, frame rate and long task measurement across device tiers), engineer perceived performance (progress feedback systems, content priority sequencing, jank masking through optimistic changes and precomputation, degradation experience design with reduced motion benefits, real reader frustration monitoring), sustain performance culture (design-time cost questions with budget allocation, CI integration with regression gates, production monitoring correlated to abandonment, team literacy with postmortems, budget-decision documentation), and avoid jank acceptance, library bloat, handler hogs, node explosion, desktop-only testing, front-loading, perception neglect, and budget amnesia failures.
