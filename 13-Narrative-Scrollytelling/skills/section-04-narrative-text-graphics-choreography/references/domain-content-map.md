# Domain Content Map — Text and Graphics Choreography: The Layout and Synchronization Systems

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module
development workflow. Verify all factual claims and numbers against the
authoritative sources before publishing (Phase 2 evidence base); flag

## Absorbed capabilities this module must produce
1. Choreograph text and graphics through layout system mastery (sticky-panel-column arrangements with ratio and offset tuning, full-bleed immersive layouts with legibility engineering, stacked-interleaved rhythms, stepper-card structures, layout selection by density-device-tone).
2. Build synchronization models (step-as-unit coupling architecture, trigger-zone design with hysteresis and scrollback, reading-rhythm coordination through text-length pacing and revelation sequencing, state continuity with shared elements and recaps, mismatch debugging), craft step text (micro-copy architecture with standalone-plus-connected sentences, text-visual division of labor avoiding redundancy, voice consistency and vocabulary scaffolding, headline-standfirst-heading integration, accessibility obligations including text-alone completeness).
3. Design graphic states (meaningful differentiation with change-magnitude calibration, layer-annotation sequencing, data-view transitions with shared-element morphing, color-emphasis state systems, storyboard documentation), and avoid wallpaper graphics, redundancy, synchronization drift, state overload, legibility sacrifice, continuity amnesia, storyboard skipping, and mobile afterthought failures.
