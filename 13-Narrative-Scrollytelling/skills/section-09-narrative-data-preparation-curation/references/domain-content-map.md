# Domain Content Map — Data Preparation and Curation for Narrative: The Story-Ready Dataset

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module
development workflow. Verify all factual claims and numbers against the
authoritative sources before publishing (Phase 2 evidence base); flag
anything disputed rather than repeating it.

## Absorbed capabilities this module must produce
1. Prepare story-ready data through narrative-specific foundations (per-step slicing with state-diff organization, curation-cherry-picking boundary with documentation obligations, narrative fidelity standards with claim traceability and encoding honesty, publication-grade quality bars with provenance and correction readiness), shape data for steps (step bundles with shared-base-plus-deltas patterns, key continuity and ordering conventions, transition-supporting matched correspondences and enter-exit sequences, multi-resolution aggregation ladders with transparency, temporal alignment and geographic simplification), engineer delivery (payload optimization with critical-path prioritization and progressive loading, caching-versioning strategies.
2. Build pipeline integration with validation, client-side management with resilience, methodology documentation and sharing decisions).
3. Run verification systems (claim-evidence audits with independent recomputation, curation review with counterexample search, edge-case and cross-step consistency checks, external peer-source-legal review integration, verification logs with limitation inventories and confidence grading), and avoid cherry-picked curation, step-data fragility, identity loss, payload bombs, verification skipping, methodology opacity, uncorrectable monoliths, and temporal manipulation failures.
