# Part A: Practical Exercises

## Exercise 1 — Operate the WCAG system (POUR hierarchy
**Scenario:** provide a realistic Accessibility scenario appropriate to the audience (real or closely modeled on documented practice).
**Objective:** operate the WCAG system (POUR hierarchy, A-AAA levels, version evolution through 2.2 with WCAG-3 awareness, Understanding-ARIA-techniques documentation, conformance-claim mechanics) applying perceivable criteria to charts (1.1.1 complex-image treatment, 1.4.3-1.4.11 contrast for text and graphical objects, reflow-resize obligations, sensory-characteristic independence, color redundancy), operable criteria (keyboard-no-trap requirements for brushes-drill-downs, target sizes, timing-motion-seizure controls, focus-order-visible navigation, single-pointer alternatives), understandable criteria (language declaration, context-change prevention, error assistance, plain language), and robust criteria (parsing, name-role-value, status messages, AT-verification imperative), navigate the complex-graphics guidance gap through task-force research, principle-based reasoning, and conformance-with-intent discipline, practice applied compliance (scope definition, AA-baseline-AAA-selective strategy, accessibility statements, VPATs, monitoring).
**Constraints:** must use the framework taught in the corresponding unit; must state assumptions and trade-offs; one deliverable, length-bounded.
**Deliverable:** the professional artifact this capability produces (memo, table, plan, analysis, or model — as applicable).
**Evaluation criteria:** correct application of the framework; decisions justified with evidence; limitations honestly stated; artifact usable by a colleague without further explanation.
