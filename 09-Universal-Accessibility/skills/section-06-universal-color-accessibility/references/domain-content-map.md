Read this during Phase 3 (architecture) and Phase 4 (writing) of the module

## Absorbed capabilities this module must produce
1. Apply CVD science (deuteran-protan-tritan taxonomy with prevalence, perceptual collision mapping, simulation-tool verification with limits awareness) to engineer safe palettes (Okabe-Ito-Tol traditions, luminance-variation ramps with viridis-cividis uniformity, blue-orange axis safety, semantic-hazard management, simulation-grayscale-contrast-user verification workflows, dark-print adaptation), enforce WCAG contrast discipline (luminance computation literacy, chart-element application for marks-axes-text-overlays, variable-background scrims-halos, composited transparency computation, aesthetics balance, automated-manual testing).
2. Build redundant encoding systems (direct labeling primary, shape-pattern companions.
3. Position-order channels, icon-status pairings, coherence conventions without clutter), support low vision through typography-scaling-decluttering-focus-visibility-magnification design, gate temporal access (three-flash seizure safety with streaming audits, universal reduced-motion integration with comprehension-preserving alternatives, distraction-audio restraint).
4. Integrate through design-system verified tokens.
5. Design-implementation-documentation workflows with exception management, prevent rainbow-red-green-legend-only-muted-pattern-only-dark-afterthought-simulation-only-transparency anti-patterns.
6. Validate via automated audits, CVD-low-vision user testing, and field accommodation telemetry.
