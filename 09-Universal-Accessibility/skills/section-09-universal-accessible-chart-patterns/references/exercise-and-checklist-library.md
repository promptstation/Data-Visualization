# Part A: Practical Exercises

## Exercise 1 — Apply the five-dimension pattern method (semantics
**Scenario:** provide a realistic Accessibility scenario appropriate to the audience (real or closely modeled on documented practice).
**Objective:** apply the five-dimension pattern method (semantics, text alternatives, keyboard model, redundancy, challenges) across chart families: bar-column (table equivalence, ranking narratives, category traversal, value labels, truncation honesty), line-area (trend-inflection-crossing narratives, x-stepping shared tooltips, direct labeling and dash patterns, density aggregation), scatter-bubble (correlation-cluster-outlier summaries, nearest-neighbor stepping, shape-label companions, overplotting alternatives), pie-donut (proportion narratives, percentage-value duals, alternative-recommendation duty), histogram-distribution (shape-skew-modality descriptions, bin stepping, statistical annotations, binning transparency), maps (ranked-region lists, spatial-pattern narratives, region-jump navigation, MAUP honesty, 2D-equivalent mandates), dashboards (region-heading landmarks, priority-ordered summaries, live-region state communication), and specialized families (network topology summaries, sankey flows, matrix grids) with template-based extension to novel types, informed by accessibility-profile chart selection, hybrid representation provision, and pattern-validation discipline against type-specific anti-patterns.
**Constraints:** must use the framework taught in the corresponding unit; must state assumptions and trade-offs; one deliverable, length-bounded.
**Deliverable:** the professional artifact this capability produces (memo, table, plan, analysis, or model — as applicable).
**Evaluation criteria:** correct application of the framework; decisions justified with evidence; limitations honestly stated; artifact usable by a colleague without further explanation.

## Exercise 2 — Integrated capstone
**Scenario:** one realistic problem spanning the whole section.
**Objective:** take the problem through every unit's framework in sequence.
**Constraints:** all unit artifacts required and internally consistent; evidence discipline maintained throughout.
**Deliverable:** a coherent campaign/portfolio document assembled as real professional documentation.
**Evaluation criteria:** consistency across artifacts; each capability demonstrably exercised; trade-offs stated at each decision point.
