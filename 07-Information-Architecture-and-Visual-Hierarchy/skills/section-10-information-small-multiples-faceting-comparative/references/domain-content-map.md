# Domain Content Map — Small Multiples, Faceting, and Comparative Arrangement

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module
development workflow. Verify all factual claims and numbers against the
authoritative sources before publishing (Phase 2 evidence base); flag
anything disputed rather than repeating it.

## Absorbed capabilities this module must produce
1. Apply small-multiples doctrine (one-design-many-instances repetition efficiency, memory-free comparison, identical-scale honesty) across the multiples-family taxonomy, engineer faceting mechanics (dimension selection with cardinality management, grid-layout computation, value-sorted ordering, shared-versus-free scale decisions with labeling obligations, empty-panel honesty), craft panel instances (minimal chrome with edge-only axes, within-panel simplification, reference-line context anchors, size-density optimization), deploy comparative arrangements (paired, ranked, matrix, sequential, nested) with interactive brushing-linking, panel escalation, dynamic facet controls, and virtualized rendering.
2. Select comparison mechanisms through instance-count-subtlety-task matrices against overlay-aggregate-animation alternatives.
3. Diagnose scale-inconsistency, proliferation, ordering-chaos, chrome-bloat, and context-loss failures.
4. Implement via framework loops, D3 nested joins, and grammar-tier facets with responsive-mobile-accessible engineering.
5. Validate through comparison-task accuracy testing and ordering-scale experiments.

## Unit 1 — Unit 1

**Scope:** Covers the comparison-structure discipline: the small-multiples doctrine — the canonical pattern: the Tufte-lineage definition (the repeated identical-design displays varying only by data subset — the one-design-many-instances principle, the comprehension-through-repetition insight: the viewer learns the format once and reads many instances efficiently), the cognitive advantages (the comparison-without-memory-burden — the simultaneous presence replacing sequential recall from the load discipline, the pattern-and-exception detection across instances — the preattentive deviation spotting, the honesty-through-identical-scales — the forced-comparability discipline), and the multiples-family taxonomy (the trellis and facet grids by one or two dimensions, the time-series panel sequences, the geographic map-matrix arrangements, the sparkline rows as compact multiples) as the pattern foundation; the faceting mechanics — the subset-generation system: the facet-dimension selection (the which-dimensions-deserve-multiples decisions — the low-cardinality categorical suitability, the high-cardinality challenges — the top-N-and-other aggregations, the cross-facet combination-explosion management — the two-dimension matrix limits), the layout computation (the grid-arrangement mathematics — the rows-by-columns decisions by aspect and count, the panel-ordering conventions — the alphabetical versus value-sorted versus logical order with the sorted-by-magnitude pattern facilitation), the shared-encoding-and-scale discipline (the identical-axes-across-panels comparability requirement, the shared-versus-free-scale decisions — the comparison-accuracy versus detail-visibility trade-off with the explicit free-scale labeling obligation), and the empty-and-sparse panel handling (the missing-combination display — the gray-empty-panel honesty versus collapse options, the sparse-data panel legibility) as the faceting mechanics; the panel-design craft — the instance engineering: the panel anatomy (the panel-title-and-subtitle conventions — the facet-value labeling clarity, the minimal-per-panel-chrome — the shared-axes deduplication via the edge-only-axis-labels pattern, the panel-content-maximization discipline), the within-panel simplification (the reduced complexity per instance — the annotation-and-detail restraint compensated by multiplicity, the direct-labeling-over-legends preference within panels), the cross-panel reference aids (the overall-average and benchmark reference lines repeated per panel — the context anchors enabling deviation reading, the highlight-linked panel interactions from the coordination discipline), and the panel-size-and-density optimization (the minimum-legible-instance sizing, the density-versus-count trade-offs — the many-small versus few-large decisions by task) as the instance craft; the comparative-arrangement patterns — the broader family: the paired-comparison layouts (the before-after, actual-versus-target, and A-B arrangements — the aligned-pair conventions with the difference-view derivations), the ranked-and-sorted arrangements (the value-ordered panel-and-row sequences — the leaderboard-and-ranking-table patterns with the rank-change indicators), the matrix arrangements (the correlation-and-scatterplot matrices — the pairwise-relationship grids, the heatmap-matrix conventions for categorical cross-tabulations), the sequential arrangements (the time-stepped panel progressions — the animation-versus-multiples decisions for temporal comparison, the filmstrip-and-storyboard patterns), and the nested-and-hierarchical comparisons (the grouped multiples — the facet-within-facet arrangements, the expandable comparison sets) as the arrangement library; the interactive small multiples — the dynamic patterns: the brushing-and-linking across multiples (the cross-panel selection coordination from section 8 — the shared brush-and-highlight mechanics), the zoom-and-detail escalation per panel (the panel-click-to-enlarge patterns — the focus-plus-context with the multiples overview retained, the panel-level drill-down preserving the grid context), the dynamic-facet controls (the facet-dimension switching — the user-selected multiple dimensions, the sort-and-filter controls on panel grids, the panel-count-and-layout adjustment), and the progressive-multiples loading (the large-panel-count rendering strategies — the virtualized grids and lazy rendering from the performance disciplines) as the interactive layer; the small multiples in genres — the applied patterns: the multi-series time comparison (the metric-panel rows for KPI-trend families — the dashboard-multiples integration), the geographic-comparison matrices (the region-and-country map multiples from the spatial discipline, the small-multiple choropleth time series), the segment-comparison grids (the demographic-and-cohort panel facets, the A-B-test result multiples), the distribution-comparison arrangements (the violin-and-histogram facet grids, the boxplot-matrix conventions), and the model-and-simulation output comparison (the scenario-and-parameter-sweep multiples — the sensitivity-analysis displays) as the genre library; the alternatives-and-complements — the comparison-toolkit context: the overlaid-comparison alternatives (the multi-series single-chart comparisons — the line-count legibility limits, the direct-labeling-over-color-coding discipline), the aggregated-comparison patterns (the grouped-and-stacked bars, the dot-and-lollipop plots for many-category comparison, the slope-and-dumbbell charts for two-point comparisons), the animated comparison (the transition-based single-view comparison with the object-constancy requirements — the when-animation-beats-multiples analysis), and the comparison-mechanism-selection framework (the instance-count-by-difference-subtlety-by-task matrix — the multiples for many subtle differences, the overlays for few large differences, the aggregations for summary judgments) as the selection discipline; the small-multiples design failures — the diagnostic library: the scale-inconsistency failure (the free-scales-without-labeling comparison destruction — the misleading-multiples pitfall), the panel-proliferation failure (the excessive-instance-count collapse — the unreadable-miniature grids, the facet-dimension overreach), the ordering-chaos failure (the arbitrary-panel-order pattern destruction — the alphabetical-ordering-hiding-trends problem), the chrome-bloat failure (the per-panel decoration accumulation causing density collapse — the repeated legends and axes waste), and the context-loss failure (the panel isolation without reference anchors causing deviation blindness) with the systematic repair patterns as the diagnostic discipline; the implementation patterns — the technical layer: the multiples-rendering approaches (the component-loop generation in frameworks — the React-Vue-Svelte facet mapping from the framework-integration discipline, the D3 nested joins for panel grids from the D3 discipline, the Plot-Vega facet declarations from the grammar tier), the responsive-multiples layouts (the grid-reflow across breakpoints — the column-count adaptation, the mobile multiples strategies — the horizontal-scroll-and-stacked-panel patterns), the multiples performance (the shared-scale-and-generator computation across panels, the panel-render batching and virtualization), and the multiples accessibility (the panel-grid navigation for keyboard and screen reader — the table-structure semantics for grids, the per-panel alternative-text-and-data access, the comparison-summary textual equivalents) as the implementation craft; the evaluation of comparison arrangements — the evidence layer: the comparison-task testing (the difference-detection-and-magnitude-judgment accuracy measurement across arrangement variants, the time-to-comparison metrics), the pattern-discovery validation (the cross-panel anomaly-detection effectiveness — the exception-spotting task performance), the ordering-and-scale experiments (the sorted-versus-alphabetical and shared-versus-free-scale A-B evidence), and the density-preference-and-performance balance (the user-preference versus task-accuracy divergence management — the accuracy-weighted decisions) as the evaluation practice;
