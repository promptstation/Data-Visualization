# Domain Content Map — Shapes, Layouts, and Geometries: The d3 Mark-Generation System

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module
development workflow. Verify all factual claims and numbers against the
authoritative sources before publishing (Phase 2 evidence base); flag

## Absorbed capabilities this module must produce
1. Generate cartesian geometry through line-area generators with curve-interpolator honesty discipline and gap handling.
2. Construct radial (arc-pie with tween transitions), stacked (offset-order semantics), and hierarchical layouts (tree-treemap-partition with tiling strategies and matching link shapes).
3. Operate force simulations with lifecycle tuning, drag pinning, and determinism caveats, deploy geo projections (family selection, fitExtent, TopoJSON integration, spherical utilities), spatial structures (Delaunay nearest-find hover patterns, Voronoi cells, quadtrees), and field generators (contour, density estimation), compose multi-generator layered charts with cached precomputed layouts and path simplification for performance.

the d3-hierarchy system — the tree-structured data: the hierarchy constructor (the children-accessor tree building, the sum-count-sort-descendants-ancestors methods, the leaf-and-path traversal utilities), the layout family (the d3-tree tidy-tree layout — the nodeSize-separation mechanics, the d3-cluster dendrogram variant, the d3-treemap space-filling layout with the squarify-reslice-sliceDice tiling strategies and the padding-rounding options, the d3-partition icicle-sunburst layouts), and the link-shape generators (the linkHorizontal-linkVertical-linkRadial curve connectors matching each layout) as the hierarchy toolkit; the force-simulation system — the physics layout: the simulation architecture (the tick-alpha-alphaDecay lifecycle, the force composition — the forceLink-forceManyBody-forceCenter-forceCollide-forceX-forceY mechanics with parameter tuning), the node-link-diagram patterns (the drag-integration with fx-fy pinning, the simulation-reheat on data change), the force-layout caveats (the nondeterminism and stability issues — the seeded-random and tick-precomputation patterns, the layout-meaning honesty — the force positions as aesthetic not analytical) as the physics-layout craft; the d3-geo system — the geographic projections: the projection architecture (the geoPath generator with projection-context, the projection families — the geoMercator-geoNaturalEarth1-geoOrthographic selection by use case, the fitExtent-fitSize auto-scaling patterns), the GeoJSON-TopoJSON data integration (the topology-preserving compression, the mesh-and-feature extraction), the spherical-geometry utilities (the geoDistance-geoInterpolate-geoBounds calculations, the great-circle arc rendering), and the projection-transitions (the interpolateProjection animated view changes) as the geo toolkit; the delaunay and voronoi system — the spatial structures: the Delaunay triangulation (the delaunayFrom-points construction, the find-nearest-neighbor query — the hover-target resolution pattern replacing per-element listeners, the render-methods for triangulation display), the Voronoi diagram derivation (the cell computation for hover-regions and spatial-binning, the cell-polygon rendering) and the quadtree (the spatial-index structure for collision detection and nearest-queries — the label-placement and force-integration uses) as the spatial-computation toolkit; the contour and density system — the field generators: the d3-contour mechanics (the marching-squares isoline extraction from gridded values, the contourDensity kernel-density estimation from point data — the bandwidth-cellSize parameters), the rendering integration (the geoPath-compatible contour polygons — the density-heatmap and uncertainty-band applications) as the field-visualization toolkit; the polygon-array-geometry utilities — the computational helpers: the d3-polygon operations (the hull convex-hull computation, the area-centroid-contains utilities), the interpolation path sampling (the path-sample point extraction along curves), and the random-distribution generators (the d3-random families for simulation and jitter) as the utility layer; the layout-composition patterns — the multi-generator charts: the combined-geometry construction (the line-plus-area confidence bands, the hierarchical-plus-force hybrids, the geo-plus-contour density maps, the voronoi-hover-over-scatter interaction layer) with the layer-ordering and clip-integration discipline as the composition craft; the shape-generation performance — the cost layer: the generator-computation caching (the path-string recomputation avoidance on static data, the precomputed-layout patterns for large hierarchies and forces — the web-worker offload option from the graphics-APIs discipline), the path-complexity management (the point-count reduction — the simplify preprocessing for dense lines, the precision-truncation of path strings) as the generation-performance practice; and the shapes-layouts deliverable — the complete geometry-generation vocabulary from cartesian through hierarchical, physical, geographic, spatial, and field systems.
