## Absorbed capabilities this module must produce
1. Engineer advanced SVG paint and visibility systems (gradients with coordinate-space control, clipPath-mask selection logic for plot areas and reveals) with filter-primitive chains under documented performance-cost governance, deploy pattern-texture fills as CVD-and-print redundant encodings and marker path decorations with attachment mechanics.
2. Execute precision craft (shape-rendering selection, half-pixel hairline alignment, path-precision management), navigate animation options (SMIL status, CSS-composited transforms, D3 interpolation) with universal reduced-motion gating.
3. Generate SVG programmatically and server-side with rasterization-export pipelines.
4. Apply foreignObject HTML hybridization under cross-browser minimal-use discipline.

## Unit 1 — Unit 1

**Scope:** Extends to the advanced medium features: the gradient system — the paint servers: the linearGradient and radialGradient mechanics (the coordinate systems — userSpaceOnUse versus objectBoundingBox, the stop-offset architecture, the gradientTransform manipulation), the gradient applications in visualization (the continuous-color-legend construction, the area-fill depth effects, the heatmap-alternative encodings) and the performance-awareness (the gradient-rendering costs in animated contexts) as the paint-engineering layer; the clipping and masking system — the visibility control: the clipPath mechanics (the hard-edge geometry clipping — the clip-path units and rule behaviors, the chart-plot-area clipping pattern preventing overflow during zoom and transitions), the mask architecture (the alpha-and-luminance masking — the soft-edge visibility control, the mask-content coordinate systems), the clip-versus-mask selection logic (the geometric-hard-edge versus painted-soft-edge decision), and the visualization applications (the focus-context fades, the animated-reveal wipes, the irregular-region emphasis) as the visibility craft; the filter system — the effects pipeline: the fe-component architecture (the filter-primitive chain model — the feGaussianBlur, feColorMatrix, feComposite, feMerge, feDropShadow, feTurbulence family with the in-in2-result dataflow), the filter-application patterns (the drop-shadow emphasis, the glow effects, the blur-based density smoothing, the displacement-map distortions at awareness), and the critical performance discipline (the documented filter-cost reality — the rasterization-pipeline expense per filtered element, the filter-region optimization — the x-y-width-height bounds, the animated-filter warning — the frame-budget killer classification) as the effects engineering with cost governance; the pattern-and-texture system — the fill complexity: the pattern element mechanics (the tiled-fill architecture — the patternUnits and patternContentUnits, the patternTransform manipulation), the data-visualization applications (the categorical texture fills for CVD-and-print redundancy — the hatch-dot-cross families from the Gestalt carrier-channel discipline, the uncertainty-band texturing, the map-area patterns), and the texture-design discipline (the scale-legibility balance — the pattern visibility at mark size, the print-and-monochrome robustness advantages) as the redundant-encoding tool; the marker system — the path decorations: the marker element mechanics (the markerStart-Mid-End attachment, the orient-auto behaviors, the markerUnits scaling), the arrow-and-glyph applications (the flow-direction arrows in sankey and trajectory graphics, the vertex markers on lines), and the marker-versus-instanced-symbol decisions (the automatic-attachment versus manual-placement trade-offs) as the decoration system; the precision-craft layer — the quality details: the shape-rendering and text-rendering optimizations (the crispEdges versus geometricPrecision selections by content type), the subpixel-alignment discipline (the half-pixel offsets for crisp hairlines — the stroke-width-alignment relationship, the transform-induced blur avoidance), the path-precision management (the decimal-place reduction for file size versus curve quality — the SVGO precision settings), and the viewBox-fraction handling (the non-integer coordinate systems and their antialiasing consequences) as the pixel-perfection craft; the SVG-animation options — the native layer: the SMIL animation elements (the animate-animateTransform-animateMotion declarative animations — the deprecated-status history and the current browser-support reality), the CSS-animation-and-transition applicability to SVG properties (the transform-and-opacity GPU-composited animations versus attribute animations requiring JavaScript), and the D3-transition positioning (the JavaScript-driven attribute interpolation as the general solution — the section-7 preview) as the animation-option map; the foreignObject and HTML integration — the hybrid content: the foreignObject mechanics (embedding HTML inside SVG — the div-in-chart capabilities: rich text, form controls, HTML-based tooltips), the sizing-and-overflow behaviors (the explicit-dimension requirements, the scrolling interactions), and the documented cross-browser fragility (the print-export inconsistencies, the transform-interaction quirks) requiring the minimal-use discipline as the hybrid technique; the SVG-generation patterns — the programmatic authoring: the string-template versus DOM-API generation (the d3-create and d3-selection authoring versus template-literal SVG strings — the parsing and injection considerations), the server-side SVG generation (the node-canvas and pure-string SSR approaches for static exports and email-compatible graphics — the email-client SVG-support caveats), and the SVG-to-other-format pipelines (the rasterization for PNG fallbacks — the canvas-drawImage and resvg-lineage converters, the PDF export paths) as the generation engineering; the advanced-feature accessibility notes — the inclusion layer: the filter-and-mask screen-reader neutrality (the effects invisible to assistive tech — the semantic-structure independence), the pattern-and-texture redundant-encoding value (the non-color carriers from the accessibility discipline), and the animation-reduction obligations (the prefers-reduced-motion coverage of SMIL, CSS, and D3 animations — the universal-motion-gating requirement) as the inclusive-advanced-craft; and the advanced-SVG deliverable — the gradient, clip-mask, filter, pattern, marker, and precision mastery with cost and accessibility governance.
