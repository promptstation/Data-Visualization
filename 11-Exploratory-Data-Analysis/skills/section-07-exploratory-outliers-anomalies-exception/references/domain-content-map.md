# Domain Content Map — Outliers, Anomalies, and the Exception Investigation

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module
development workflow. Verify all factual claims and numbers against the
authoritative sources before publishing (Phase 2 evidence base); flag
anything disputed rather than repeating it.

## Absorbed capabilities this module must produce
1. Hunt and handle exceptions through conceptual grounding (outlier-anomaly-error taxonomy with contextual-global distinctions, discovery-stance attitude discipline, generation-mechanism understanding, expectation-dependence honesty with method plurality), screen univariates (Tukey fences with skew adjustment, classical-versus-robust z-scores with masking awareness, percentile and Q-Q approaches, categorical rarity, exception visualization conventions).
2. Detect in joint context (leverage-influence reading with removal sensitivity, Mahalanobis distances with robustness caveats, residual and local-density deviations, cluster isolation, consistent cross-view flagging), handle temporal exceptions (contextual spike detection, changepoint and regime shifts, pattern-peer and absence anomalies, sequence gaps, context-window displays).
3. Run investigation protocols (triage classification with domain consultation, provenance tracing, impact sensitivity assessment, keep-flag-transform-remove decision matrices with documentation and parallel analysis, narrative communication), and avoid deletion-reflex, z-masking, fence-misapplication, marginal-only, seasonal-blindness, tunnel-vision, undocumented-treatment, and suppression failures.
