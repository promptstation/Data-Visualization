## Absorbed capabilities this module must produce
1. Navigate multivariate structure through challenge framing (pair-explosion arithmetic, strategy families of matrix-reduction-hierarchy-focus, target orientation, foundation-first ordering).
2. Operate SPLOM systems (construction conventions with triangle differentiation.
3. Design decisions for scale and brushing, scanning-persistence-spotting reading protocols, conditional-compressed-interactive variants), deploy parallel coordinates (axis-scaling-ordering mechanics, bundle-cluster-outlier pattern vocabulary, drag-brush-hover interactions, limitation remedies), project via reduction views (PCA score-biplot conventions, t-SNE-UMAP with hazard discipline and stability checks, MDS awareness, embedding-feature linking workflows), explore variable meta-structure (clustered correlation heatmaps, redundancy-factor identification, variable clustering, importance screening intuitions, role-shape archetypes).
4. Run staged workflows (screening-focused-verification protocols, subgroup discovery loops, interactive navigation compositions, documentation inventories), and avoid pair-paralysis, SPLOM-overload, axis-blindness, embedding-overinterpretation, reduction-abandonment, importance-reification, and documentation-gap failures.
