# Domain Content Map — Time-Series Exploration: Temporal Structure Discovery

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module
development workflow. Verify all factual claims and numbers against the
authoritative sources before publishing (Phase 2 evidence base); flag

## Absorbed capabilities this module must produce
1. Explore temporal structure through foundations (timestamp auditing, series-shape classification, time-axis construction decisions, line-plot-first doctrine), investigate trends (visual assessment with scale caveats, classical-STL decomposition with display conventions and parameter sensitivity, rolling statistics with lookahead avoidance, changepoint detection, detrending workflows), discover seasonality (domain-guided period hypotheses, seasonal-subseries and overlay displays, ACF reading with seasonal peaks, periodogram awareness, evolution and segment investigation, multi-seasonality handling), examine residuals (time-distribution-autocorrelation battery, anomaly overlays, stationarity intuitions with variance stabilization, volatility assessment, artifact honesty).
2. Compare multi-series and panels (aligned overlays, small multiples, normalization rebasing.
3. Lead-lag and behavior clustering, cohort alignment, interactive navigation).
4. Run integrated protocols (staged batteries, context documentation registers, forecasting handoff summaries, annotated communication), and avoid timezone-naive, gap-blind, parameter-cherry-picking, seasonal-confounding, lookahead-bias, spaghetti-overlay, pooling-homogeneity, and residual-artifact failures.
