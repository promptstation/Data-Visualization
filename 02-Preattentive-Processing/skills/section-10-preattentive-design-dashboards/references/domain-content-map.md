# Domain Content Map — Preattentive Design for Dashboards: Emphasis, Alerts, and Glanceability

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module
development workflow. Verify all factual claims and numbers against the
authoritative sources before publishing (Phase 2 evidence base); flag
anything disputed rather than repeating it.

## Absorbed capabilities this module must produce
1. Engineer glanceable dashboards through three-tier emphasis hierarchies allocating channels by decision-criticality.
2. Design alert systems with criticality-channel mapping, presentation-context trade-offs, and lifecycle states preventing fatigue, craft KPI-number, heatmap, status-grid.
3. Map emphasis with CVD-redundancy and area-confound awareness, extend to ambient control-room displays with distance-hardened channels and multi-screen routing.
4. Implement interactive salience (hover feedback, filter updates, cross-filter propagation) within latency budgets.
5. Validate through seconds-tests, seeded-anomaly trials, and production fatigue telemetry.

## Unit 1 — Unit 1

**Scope:** Applies the science to the dashboard craft: the glanceability concept — the dashboard ideal: the single-fixation comprehension target (the documented glanceable-design research — what can be extracted in under-250ms: the gross state, the presence of exceptions, the dominant trend direction) defining the preattentive layer's job — the state-at-a-glance readout before any deliberate inspection; the emphasis-hierarchy architecture — the tiered salience plan: the three-tier emphasis system (tier one: the decision-critical exception signals using the strongest channels — motion-onset, high-luminance-contrast, isolated position; tier two: the status-overview structure using mid-strength channels — color families, size gradations, region containment; tier three: the reference detail at baseline salience — quiet, uniform, receding) with the channel-allocation per tier as the salience-budget plan; the alert-design system — the exception-signaling craft: the alert-channel selection (the criticality-to-channel mapping — the life-critical versus informational tiers using motion-and-luminance versus color-only signaling, the audible-visual pairing for the unattended displays), the alert-presentation patterns (the in-place highlight versus banner-intrusion versus dedicated-alert-panel trade-offs — the capture-versus-context spectrum, the annotation-linked alert connecting signal to explanation), and the alert-state lifecycle (the new-acknowledged-resolved visual states preventing re-capture of handled alerts — the alert-fatigue mitigation); the KPI-and-number emphasis — the scalar-display craft: the big-number dashboard patterns (the KPI-tile salience design — the size-and-weight hierarchy across tiles, the change-indicator channels — the arrow-color-sparkline combinations, the threshold-crossing state changes — the conditional-formatting as applied preattentive encoding) with the number-comparison support (the aligned-decimal and tabular-figure conventions enabling the preattentive length-parsing, the reference-line and target-marker emphasis); the status-overview patterns — the field-display craft: the heatmap-and-status-grid glanceability (the color-field anomaly visibility — the single-off-color-cell pop in uniform grids, the density limits where cell-level pop fails and region-level structure takes over), the traffic-light conventions (the red-amber-green cultural-channel double-duty with the CVD-redundancy obligation — the shape-or-icon companions), and the small-multiples monitoring walls (the cross-panel exception scan — the identical-form violation detection, the panel-order and highlight-consistency requirements); the map-and-spatial dashboards — the geographic layer: the choropleth and symbol-map salience (the regional-color-cluster reading as preattentive pattern, the outlier-region pop, the map-specific pitfalls — the area-size salience confound: large regions dominating regardless of value, the classification-scheme effects on pattern salience) with the spatial-exception signaling (the cluster-hotspot highlighting, the animation for emerging spatial patterns); the multi-screen and control-room context — the ambient-display tier: the wall-display design (the viewing-distance channel selection — the size, luminance, and motion channels surviving distance where color-hue and form detail fail, the ambient-peripheral design from section 9's divided-attention mode), the multi-monitor salience coordination (the cross-screen attention routing — the beacon patterns drawing gaze between screens), and the lighting-environment calibration (the control-room dim versus office bright contrast-ratio adjustments) as the environment-hardened salience design; the interactive emphasis layer — the dynamic salience: the hover-and-selection feedback (the immediate-state-change as the responsiveness signal — the under-100ms feedback rule connecting to the latency course 8, the highlight-and-dim interaction patterns), the filter-and-drill salience updates (the re-computation of emphasis after interaction — the context-changed re-salience), and the cross-filter-linked highlighting (the coordinated-view emphasis propagation — the course-1 common-fate dynamics applied to interaction) as the responsive-salience system; the glanceability testing — the validation practice: the five-second-and-shorter tests (the state-extraction protocols — what did you see? anything wrong? which panel matters most?), the exception-detection timed trials (the seeded-anomaly find-time measurement across design variants), and the alert-fatigue longitudinal observation (the acknowledged-ignoring rates in production) as the dashboard-salience evidence system; the dashboard anti-patterns — the failure catalog: the everything-critical dashboard (uniform loud styling — the salience-flatline), the alert-storm design (every threshold firing motion alerts — the bottleneck saturation), the decoration-competition (branding and imagery out-salienting data — the chrome-flip), and the glance-oracle gap (designs requiring reading to know if attention is needed — the state-invisibility failure) as the hygiene rules; and the dashboard deliverable — the tiered, tested, fatigue-resistant emphasis system.
