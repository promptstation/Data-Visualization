## Absorbed capabilities this module must produce
1. Run visual-search assays (target-detection across set sizes, presence-absence asymmetry, singleton-detection thresholds) interpreting search-slope continua (flat-parallel versus steep-serial signatures).
2. Build practical designer-run tests with browser experiment tooling, naive participants, and randomized protocols, calibrate design parameters (size deltas, saturation drops, palette rankings, density tolerances) through difference-threshold measurement.
3. Integrate signal-detection accuracy measures and eye-tracking first-fixation analysis, and balance lab calibration with field validation using benchmark priors while avoiding set-size, practice-effect, calibration, and slope-obsession pitfalls.

## Unit 1 — Unit 1

**Scope:** Builds the measurement discipline: the search-paradigm core — the instrument: the target-detection experiment formalized (the display of distractor items with or without a target differing by the tested feature, the response-time and accuracy measurement across set sizes — the display-item-count manipulation) as the standard preattentivity assay inherited from the feature-integration research program; the search-slope metric — the verdict scale: the RT-by-set-size regression slope interpretation (the flat-slope criterion — the documented roughly-under-10-ms-per-item threshold region indicating parallel pop-out processing, the steep-slope serial-search signature at 25-60+ ms per item, the intermediate guided-search slopes) making preattentivity a measured continuum rather than a binary label; the presence-absence asymmetry design — the protocol detail: the target-present versus target-absent trial analysis (the absent-trial slopes typically double the present-trial slopes under serial search — the exhaustive-search signature, the parallel-search equivalence) as the diagnostic pair distinguishing processing modes; the singleton-detection paradigm — the complementary assay: the odd-one-out displays measuring the feature-difference detection without set-size search (the reaction-time-by-contrast-magnitude curves — the difference-threshold mapping) quantifying how much contrast a channel needs to pop reliably — the salience-calibration instrument; the feature-versus-conjunction comparison — the classic design: the within-experiment contrast (the same elements tested as single-feature targets versus conjunction targets — the slope divergence demonstrating the integration cost) as the teaching-and-verification protocol for design teams; building practical search tests — the designer's workflow: the display-capture preparation (screenshotting real dashboard states at realistic densities), the participant protocol (the naive-viewer recruitment from course 1, the trial-count and randomization requirements for stable slopes, the practice-trial conventions), the low-cost tooling (the browser-based experiment frameworks — the jsPsych-PsychoPy-lineage tools, the timed-response web forms as the minimum viable apparatus) making search testing a designer-runnable method; the threshold-finding applications — the calibration use: the difference-threshold measurement for design parameters (how much size increase makes the key symbol pop? how much saturation drop dims the background sufficiently? — the parameter-tuning experiments), the palette-salience ranking (the candidate color sets tested for singleton-detection speed — the evidence-based palette selection), and the density-tolerance mapping (the clutter level at which the emphasis channel degrades — the operating-envelope measurement); the accuracy-RT complement — the dual-measure discipline: the speed-accuracy trade-off awareness (the RT-only readings missing accuracy costs — the false-alarm and miss-rate measurement, the signal-detection-theory framing — d-prime and criterion as the sensitivity measures separating sensitivity from response bias) upgrading the naive RT analysis; the eye-tracking integration — the gaze complement: the search-task gaze patterns (the first-fixation latency to target as the direct capture measure, the scanpath-efficiency analysis — the path length to detection, the distractor-fixation counts as the competition measure) combining the course-1 eye-tracking methods with search paradigms for mechanism-level diagnosis; the field-versus-lab tension — the validity balance: the controlled-search artificiality (simplified displays, single tasks, laboratory viewing) versus the real-dashboard complexity (multiple tasks, prior knowledge, motivated viewers — the guided-search top-down factor), with the hybrid strategy (lab tests for channel-parameter calibration, field A/B tests and telemetry for in-context validation — the two-tier evidence system); the benchmark literature — the reference values: the documented published search-slope values for the standard features (the orientation, color, size, motion benchmarks from the experimental literature) as the prior-expectation table reducing routine local testing, with the transfer-caution (benchmark displays differ from dense real charts — the local-verification requirement for high-stakes emphasis); the measurement anti-patterns — the methodology pitfalls: the set-size-too-small error (slopes unreliable below the item-count thresholds), the practice-effect contamination (learning curves inflating early-trial RTs — the warm-up and block-order controls), the display-calibration neglect (screen brightness and color variance across participant devices in remote testing — the uncontrolled-monitor problem), and the slope-obsession (ignoring intercept and accuracy — the full-curve reading discipline); and the search-measurement deliverable — the designer-run search-testing capability producing slopes, thresholds, and calibration curves for salience decisions.
