# Measuring Preattention: The Visual Search Paradigm and Search-Slope Literacy — Professional Training

## Mission

Produce professional-grade learning modules and training materials on **measuring Preattention: The Visual Search Paradigm and Search-Slope Literacy** within The science of visual attributes (color hue, size, orientation, motion) processed in milliseconds before conscious attention — engineered to direct the viewer's eye instantly in data visualization.

Subject scope: Builds the measurement discipline: the search-paradigm core — the instrument: the target-detection experiment formalized (the display of distractor items with or without a target differing by the tested feature, the response-time and accuracy measurement across set sizes — the display-item-count manipulation) as the standard preattentivity assay inherited from the feature-integration research program; the search-slope metric — the verdict scale: the RT-by-set-size regression slope interpretation (the flat-slope criterion — the documented roughly-under-10-ms-per-item threshold region indicating parallel pop-out processing, the steep-slope serial-search signature at 25-60+ ms per item, the intermediate guided-search slopes) making preattentivity a measured continuum rather than a binary label; the presence-absence asymmetry design — the protocol detail: the target-present versus target-absent trial analysis (the absent-trial slopes typically double the present-trial slopes under serial search — the exhaustive-search signature, the parallel-search equivalence) as the diagnostic pair distinguishing processing modes; the singleton-detection paradigm — the complementary assay: the odd-one-out displays measuring the feature-difference detection without set-size search (the reaction-time-by-contrast-magnitude curves — the difference-threshold mapping) quantifying how much contrast a channel needs to pop reliably — the salience-calibration instrument; the feature-versus-conjunction comparison — the classic design: the within-experiment contrast (the same elements tested as single-feature targets versus conjunction targets — the slope divergence demonstrating the integration cost) as the teaching-and-verification protocol for design teams; building practical search tests — the designer's workflow: the display-capture preparation (screenshotting real dashboard states at realistic densities), the participant protocol (the naive-viewer recruitment from course 1, the trial-count and randomization requirements for stable slopes, the practice-trial conventions), the low-cost tooling (the browser-based experiment frameworks — the jsPsych-PsychoPy-lineage tools, the timed-response web forms as the minimum viable apparatus) making search testing a designer-runnable method; the threshold-finding applications — the calibration use: the difference-threshold measurement for design parameters (how much size increase makes the key symbol pop? how much saturation drop dims the background sufficiently? — the parameter-tuning experiments), the palette-salience ranking (the candidate color sets tested for singleton-detection speed — the evidence-based palette selection), and the density-tolerance mapping (the clutter level at which the emphasis channel degrades — the operating-envelope measurement); the accuracy-RT complement — the dual-measure discipline: the speed-accuracy trade-off awareness (the RT-only readings missing accuracy costs — the false-alarm and miss-rate measurement, the signal-detection-theory framing — d-prime and criterion as the sensitivity measures separating sensitivity from response bias) upgrading the naive RT analysis; the eye-tracking integration — the gaze complement: the search-task gaze patterns (the first-fixation latency to target as the direct capture measure, the scanpath-efficiency analysis — the path length to detection, the distractor-fixation counts as the competition measure) combining the course-1 eye-tracking methods with search paradigms for mechanism-level diagnosis; the field-versus-lab tension — the validity balance: the controlled-search artificiality (simplified displays, single tasks, laboratory viewing) versus the real-dashboard complexity (multiple tasks, prior knowledge, motivated viewers — the guided-search top-down factor), with the hybrid strategy (lab tests for channel-parameter calibration, field A/B tests and telemetry for in-context validation — the two-tier evidence system); the benchmark literature — the reference values: the documented published search-slope values for the standard features (the orientation, color, size, motion benchmarks from the experimental literature) as the prior-expectation table reducing routine local testing, with the transfer-caution (benchmark displays differ from dense real charts — the local-verification requirement for high-stakes emphasis); the measurement anti-patterns — the methodology pitfalls: the set-size-too-small error (slopes unreliable below the item-count thresholds), the practice-effect contamination (learning curves inflating early-trial RTs — the warm-up and block-order controls), the display-calibration neglect (screen brightness and color variance across participant devices in remote testing — the uncontrolled-monitor problem), and the slope-obsession (ignoring intercept and accuracy — the full-curve reading discipline); and the search-measurement deliverable — the designer-run search-testing capability producing slopes, thresholds, and calibration curves for salience decisions.

Write as an experienced practitioner, not as a summarizer of popular content. Every framework taught must be something a real team or professional could run: procedures they can execute, criteria they can judge with, and artifacts they can hand to a colleague. Do not present claims as settled when the field treats them as contested — the training must model evidence discipline.

## Anti-Patterns

Avoid: Salience inflation — highlighting everything until nothing pops; preattentive power is relative and budget-limited, diluted by overuse (the cry-wolf effect on the salience map); Confusing salience with meaning — a popped element directs the eye but carries no interpretation; preattentive capture without deliberate-support structure leaves viewers looking at the right place without understanding; Conjunction blindness — expecting combinations of features (red AND large AND tilted) to pop when only single features do, producing serial-search tasks mislabeled as glances; Habituation neglect — persistent highlights and badges losing capture power through neural adaptation, the alert-fatigue dynamic killing always-on emphasis; Accessibility-assumed pop — preattentive effects varying with color vision (hue channels degraded for CVD viewers) and age, single-channel salience failing for part of the audience; exercises without evaluation criteria; modules that stop at inspiration without a single decision the learner can now make better; and any content that overstates certainty beyond what the evidence supports.

## Decision Heuristic

When allocating depth under time or length limits, ask:

1. Where will this audience actually stall in practice?
2. Which unit protects the most value if taught well?
3. Can the learner run the framework tomorrow without me?
4. Is every example doing work a plain sentence could not?
5. What would a skeptical domain expert say about this material?

If two topics compete for space, keep the one that changes a decision.
