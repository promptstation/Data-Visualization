## Unit 1 — Unit 1

**Scope:** Builds the mechanism model: the early-vision pipeline — the processing stages: the retinal and LGN preprocessing (the center-surround receptive fields as the first contrast-computation layer — the lateral-inhibition machinery enhancing edges and differences before cortex), the cortical feature extraction (the V1 simple and complex cells as orientation, spatial-frequency, and motion-direction filters — the documented channel-selective neuron populations), and the parallel-channel architecture (multiple feature maps computed simultaneously across the visual field) as the hardware whose structure determines the preattentive channel list; the channel concept formalized — the feature-map logic: each visual attribute processed in its own topographic map (the orientation maps, color-opponent maps, motion maps — the retinotopic organization), with within-channel competition (a singleton in one channel dominating that map) and cross-channel interaction (the combination rules) explaining why single features pop and conjunctions often don't; feature-integration theory — the binding architecture: Treisman's model formalized (the preattentive feature stage registering properties in parallel across maps, the focused-attention stage binding features into objects serially — the illusory-conjunction evidence for the two-stage split: features from unattended objects combining wrongly when attention is overloaded), with the design translation (make the important thing a single-feature difference wherever possible; reserve conjunctions for secondary structure); the salience-map concept — the integration layer: the convergence architecture (the feature maps feeding a combined priority representation — the winner-take-all dynamics selecting the next attention target), the documented neurophysiology at awareness depth (the LIP and superior-colliculus priority-map findings, the Itti-Koch computational saliency model as the engineering analog), and the map's properties (contrast-based, context-dependent, suppressible by top-down task sets per the guided-search model); guided search — the hybrid model: Wolfe's synthesis (bottom-up salience weighting the candidate set while top-down task knowledge — what the viewer is looking for — filters and weights channels, producing the observed intermediate search slopes), making real dashboard reading a guided-search process where both display salience and viewer task-set matter — the design lever being channel choice matched to the viewer's expected question; contrast-relativity principle — the context law: preattentive strength as relative difference not absolute value (the singleton advantage — one red dot among gray pops regardless of which red; the same red dot among rainbow colors does not — the distractor-heterogeneity effect), making salience a composition property (background uniformity as the enabling condition — the quiet-canvas requirement); spatial-frequency and scale structure — the resolution layer: the multi-scale processing architecture (the channel systems analyzing coarse-to-fine spatial frequencies — the low-frequency-first global parse, the coarse-scale salience advantage for large structure) explaining why squint-tests work (the course-1 audit validated by mechanism) and why tiny differences in dense fields fail to pop; the temporal window — the timing structure: the integration-time constants (the documented tens-of-milliseconds windows for feature extraction, the brief-presentation paradigms proving preattentive sufficiency), the masking and persistence effects (the iconic-memory buffer), and the implication for dynamic displays (change rates against integration windows — the section-13 streaming preview); the attentional-blink and refractory dynamics — the serial bottleneck: the documented limits of even parallel processing (the attentional-blink phenomenon — second targets missed within half a second of the first, the refractory periods in rapid detection) informing multi-signal timing (staggering alerts, sequencing highlights — the capture-scheduling craft); the architecture-to-design mapping — the synthesis table: each architectural property translated to a design rule (channels → use single-feature differences; relativity → quiet backgrounds; scales → coarse-structure emphasis; windows → change-rate limits; bottlenecks → alert staggering) as the mechanism-grounded practice bridge; the model-honesty note — the science status: the two-stage picture as productive simplification (the continuous-attention and recurrent-processing critiques, the graded-salience reality versus binary pop-out) with the engineering stance (the models predict well enough to design and test against — the evidence-over-theory-debate discipline); and the architecture deliverable — the channel-map-salience mental model grounding every downstream design decision.
