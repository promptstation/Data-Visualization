# Domain Content Map — Designing for Expertise: Adaptive Load Across the Skill Spectrum

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module
development workflow. Verify all factual claims and numbers against the
authoritative sources before publishing (Phase 2 evidence base); flag
anything disputed rather than repeating it.

## Absorbed capabilities this module must produce
1. Model audience expertise spectra with schema-automation load relativity and dashboard-literacy developmental arcs, architect novice support (guided runs, vocabulary tooltips, worked exemplars, fading plans) and expert acceleration (shortcuts, saved views, batch interfaces, density options) with interference avoidance, deploy telemetry-informed and role-based adaptation within transparency, override, and privacy boundaries guaranteeing static fallbacks, compose mixed-audience layers (depth-tiers, dual registers, presentation modes) with in-context knowledge supply.
2. Manage lifecycle shifts (tenure trajectories, turnover resets, seasonal novices) preventing permanent-novice, expert-only, adaptation-creep, and telemetry-overreach failures.

## Unit 1 — Unit 1

**Scope:** Covers the audience-capacity dimension: the expertise-spectrum frame — the load-relativity principle: the same display imposing different load compositions across the expertise range (the novice's high-extraneous decoding load versus the expert's automated reading — the schema-automation dividend, the novice's germane-heavy learning investment versus the expert's pure task load) making single-audience load optimization structurally impossible — the expertise-reversal effect from section 6 generalized into the adaptation mandate; the dashboard-literacy developmental arc — the schema-acquisition path: the documented progression (the chart-convention learning — the encoding-decoding automation timeline, the metric-vocabulary acquisition — the domain-schema building, the navigation-mastery — the wayfinding automation, the exception-pattern recognition — the anomaly-schema development) with the stage-characteristics (the novice's serial-decoding and scaffold dependence, the intermediate's convention-fluency with analysis effort, the expert's preattentive reading with schema-driven pattern detection) as the audience-model; the novice-support architecture — the onboarding load design: the scaffold toolkit (the guided-first-runs — the section-5 pre-training and worked-example applications, the encoding-legends and definition-tooltips — the vocabulary support, the annotated-exemplar readings — the worked-analysis patterns, the suggested-starting-points — the default-view and recommended-path designs) with the scaffold-fading plan (the tenure-triggered withdrawal, the user-controlled persistence — the never-force-removal discipline) as the entry-load system; the expert-acceleration architecture — the efficiency load design: the power-user toolkit (the keyboard-shortcut systems — the automated-interaction schemas, the saved-view and bookmark infrastructures — the personalized-default accumulation, the batch-and-script interfaces — the API and export access for programmatic use, the density-maximization options — the compact-mode toggles) with the expert-interference avoidance (the dismissible-scaffolds, the skip-controls on animations and tours, the stable-convention preservation — the expert-schema-respect: don't-redesign-what-experts-automated) as the efficiency-load system; the adaptive-display strategies — the dynamic adjustment: the telemetry-informed adaptation (the usage-pattern inference — the interaction-sophistication signals driving default adjustments: the disclosure-depth, annotation-density, and terminology-level personalization), the role-based view architecture (the persona-variant dashboards — the executive-analyst-operator versions sharing data infrastructure with load-profile differentiation), and the adaptation-ethics boundaries (the transparency-of-adaptation, the user-override controls, the privacy-compliant inference — the personalization-course boundaries applied) as the adaptive layer with the static-fallback guarantee (the adaptation never removing access to the full-function baseline); the mixed-audience compositions — the simultaneous-service patterns: the layered-information architecture serving ranges (the glance-tier for executives, the detail-tier for analysts, the raw-tier for specialists — the depth-layers as audience-layers per the section-9 disclosure system), the progressive-vocabulary design (the plain-language defaults with technical-term availability — the dual-register labeling), and the shared-view negotiation (the cross-role meeting displays — the presentation-mode conventions balancing the room's mixed expertise) as the multi-audience craft; the training-and-documentation load interface — the knowledge-supply system: the in-context help architecture (the definition-popovers, the methodology-notes, the calculation-transparency links — the just-in-time knowledge supply reducing prerequisite intrinsic load), the onboarding-curriculum connection (the dashboard-tutorials building the schemas the display assumes — the training-design coordination), and the documentation-as-load-relief (the metric-dictionary and FAQ systems — the asynchronous schema support) as the knowledge infrastructure; the expertise-measurement practice — the audience assessment: the user-expertise profiling methods (the usage-telemetry sophistication indicators — the feature-breadth and interaction-pattern analysis, the direct-assessment instruments — the chart-literacy and domain-knowledge short tests, the interview-based mental-model elicitation) with the persona-validation discipline (the assumed-versus-actual expertise audit — the persona-reality check) as the adaptation-evidence base; the lifecycle-load dynamics — the temporal audience shift: the user-tenure trajectory (the same individual moving novice-to-expert — the longitudinal load-profile shift requiring the fading-scaffold and progressive-revelation systems, the onboarding-to-mastery journey design), the turnover-and-refresh realities (the organizational churn resetting the audience expertise distribution — the perpetual-onboarding requirement, the seasonal-user patterns — the quarterly-review audience returning novice each cycle) as the temporal-adaptation planning; the adaptation anti-patterns — the failure catalog: the permanent-novice-treatment (the un-faded scaffolds patronizing and slowing experts — the expertise-reversal institutionalized), the expert-only-assumption (the convention-dense displays with zero onboarding — the implicit-prerequisite gatekeeping), the adaptation-creep (the personalized interfaces diverging into unrecognizable variants — the consistency-schema destruction), and the telemetry-overreach (the expertise inference from surveillance-grade monitoring — the privacy-trust violation) as the adaptation-hygiene rules; and the expertise-adaptation deliverable — the spectrum-serving load architecture with fading scaffolds, expert acceleration, and ethical adaptation.
