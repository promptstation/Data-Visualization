# Domain Content Map — Capacity Limits and Chunking: The Four-Slot Working Set

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module
development workflow. Verify all factual claims and numbers against the
authoritative sources before publishing (Phase 2 evidence base); flag
anything disputed rather than repeating it.

## Absorbed capabilities this module must produce
1. Specify working-memory constraints (four-chunk consensus, decay timescales, resource-precision trade-offs) and engineer display-side chunking through grouping, small multiples, aggregation, and labeling.
2. Run working-set analyses counting simultaneous holds per task against capacity with set-reduction strategies (embedded references, direct labels, computed differences), exploit external-memory, saccade-refresh, and annotation-rehearsal maintenance mechanisms, accommodate span variance with low-span-conservative defaults and schema-elevated chunk quality.
3. Validate through recall probes and comparison-degradation curves preventing overflow, chunk-destruction, rehearsal-hostile, and false-chunking failures.

the precision-resource trade-off — the quality dimension: the resource-model application (the fixed-capacity division across held items — the more elements held, the coarser each representation: the four-series-comparison precision loss versus the two-series precision), the design responses (the comparison-narrowing tools — the highlight-and-dim focusing, the selected-series isolation toggles, the sequential-comparison scaffolds — the A-then-B-then-difference patterns) trading simultaneous-hold quantity for per-item precision; the capacity anti-patterns — the failure catalog: the working-set-overflow design (the six-simultaneous-comparison table requiring external aids — the unacknowledged-overflow failure), the chunk-destruction (the over-styling fragmenting natural groups — the decoration-cost: every gradient and effect splitting one chunk into many), the rehearsal-hostile layout (the compared elements across screen-diagonals — the saccade-cost maximization), and the false-chunking (the visually grouped elements that are analytically unrelated — the misleading-chunk liability);
