## Absorbed capabilities this module must produce
1. Apply the coherence principle through seductive-detail elimination and decision-relevance audits, navigate the redundancy principle distinguishing harmful duplicate-processing from beneficial complementary and accessible redundancy through the keep-cut decision framework, counter expertise reversal with toggleable scaffolds, segmented versions, fading supports, and telemetry-informed adaptation within privacy boundaries, deploy worked-example and completion progressions as analytic onboarding with variability supports for transfer.
2. Validate effects through with-without variant testing and novice-expert split analyses with magnitude-transfer caution.

## Unit 1 — Unit 1

**Scope:** Covers the subtraction-and-moderation effects: the coherence principle — the less-is-more finding: the documented comprehension improvement from removing interesting-but-irrelevant material (the seductive-details effect: entertaining additions degrading learning and recall — the anecdote, decoration, and bonus-metric costs), with the dashboard applications (the decorative-chrome elimination, the vanity-metric pruning — the metric-count discipline per view, the interesting-tangent panel removal) as the coherence audit: every element passing the decision-relevance test or being cut; the redundancy principle — the duplication cost: the documented finding that identical information presented simultaneously in multiple forms can degrade rather than help (the triple-presentation overload — the narrated text that is also displayed verbatim, the same value in chart, table, and callout competing for processing), with the critical distinction (redundant-presentation of identical text versus redundant-encoding of complementary aspects — the section-2 dual-channel benefit and the course-2 CVD redundancy surviving: redundancy harms when it forces duplicate processing of the same channel content, helps when channels carry complementary or reinforcing structure) requiring the redundancy-type analysis before cutting or adding; the redundancy-decision framework — the applied rule: the test questions (does the duplicate demand re-processing or offer verification? is the audience reading or listening? does removal strand a channel-dependent subgroup?) with the documented patterns (the identical-text-plus-audio redundancy cut, the value-label-plus-precise-axis duplication judgment by task, the accessible-redundancy preservation — the alt-text and data-table companions as obligation not waste) as the keep-cut decision practice; the expertise-reversal effect — the moderator finding: the documented reversal where instructional supports benefiting novices become redundant or harmful for experts (the worked-example effect fading as schemas form, the guidance becoming noise for the automated reader — the expert's schema-driven processing conflicting with externally-imposed structure), with the mechanism (the expert's long-term schemas making explicit scaffolding redundant re-processing — the section-3 expertise-shift realized) as the single-design-serves-neither warning; the expertise-adaptation strategies — the reversal responses: the layered-scaffold design (the toggleable annotations, the collapsible guidance, the progressive-complexity views — the user-controlled scaffolding), the audience-segmented versions (the novice-guided and expert-dense variants of the same data — the role-based dashboard patterns), the fading-support sequences (the onboarding-to-power-user trajectory with scaffolds withdrawing — the training-wheel cadence from section 3), and the expertise-detection heuristics (the usage-history and interaction-pattern inference enabling adaptive defaults — the telemetry-informed adaptation with the privacy and creepiness boundaries) as the adaptation toolkit; the worked-example and completion effects — the learning-load pair: the documented worked-example superiority over problem-solving for novices (the example-study load advantage) and the completion-problem progression (the partially-worked examples bridging to independent analysis) with the dashboard translation (the annotated exemplar analyses — the 'here's how to read this exception' guided cases, the template-comparison patterns, the insight-callouts as worked readings that fade with user tenure) as the analytic-onboarding craft; the variability-and-context effects — the transfer supports: the documented varied-examples benefit for schema generalization (the multiple-context worked examples building flexible schemas) with the dashboard application (the benchmark-and-historical-context panels enabling the comparison-schema activation, the scenario-variation displays — the what-if and period-comparison tools) as the germane-load cultivation; the effect-interaction matrix — the combination science: the documented interactions among effects (the signaling-coherence synergy — cues on a coherent display; the redundancy-signaling tension — is the highlight a signal or a duplication? the expertise-reversal spanning most effects — each aid's value flipping with expertise) as the composition-awareness table preventing mechanical checklist application; the domain-knowledge prerequisite — the intrinsic load's hidden component: the viewer's background-knowledge dependence (the metric-definition literacy, the domain-relationship familiarity, the chart-convention knowledge as invisible intrinsic load — the same display carrying different intrinsic loads for different knowledge states) with the assessment practice (the knowledge-prerequisite inventory per display — what must the viewer already know, and where is that knowledge supplied?) as the hidden-load audit; the effect-measurement practice — the validation layer: the variant-testing protocols for each effect (the with-without-scaffold comparisons, the novice-expert split analyses, the workload-scale and performance triangulation from section 11 preview) with the effect-size realism (the laboratory multimedia effects attenuating in context — the directionally-reliable, magnitude-uncertain transfer caution) as the evidence discipline; and the toolkit-II deliverable — the subtraction, redundancy-judgment, and expertise-adaptation practice completing the effect system.
