# Domain Content Map — Navigation Load and Information Foraging: Finding Without Fatigue

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module
development workflow. Verify all factual claims and numbers against the
authoritative sources before publishing (Phase 2 evidence base); flag
anything disputed rather than repeating it.

## Absorbed capabilities this module must produce
1. Engineer information foraging through scent design (descriptive labels, previews, task-vocabulary matching, breadcrumb visibility) against cost-value foraging economics.
2. Manage orientation load with persistent anchors, transition continuity, and overview maps countering lost-in-hyperspace re-orientation taxes.
3. Optimize navigation structures via breadth-depth trade-offs, frequency-weighted paths, and consistent grammars, support search-filter wayfinding with state visibility and interruption resumption patterns.
4. Adapt to mobile viewport constraints.
5. Measure through path telemetry, task-time decomposition, and disorientation-event tracking preventing scent-free, context-destroying, filter-amnesia, and hierarchy-first failures.

## Unit 1 — Unit 1

**Scope:** Covers the wayfinding-cost dimension: information-foraging theory — the navigation model: the Pirolli-Card framework (users as foragers following information scent — the cue-trails suggesting value ahead, with the cost-value economics: navigation paths chosen by expected-information-gain per interaction-cost) as the theory of dashboard and analytics-system wayfinding, making navigation design a scent-engineering discipline; the scent-craft — the cue design: the documented scent strengtheners (the descriptive-over-generic labels — 'Q3 Revenue Exceptions' over 'Details', the preview-snippets and thumbnails signaling content, the consistent-terminology matching the user's task vocabulary, the breadcrumb-trail state visibility) and the scent-killers (the mystery-icons, the jargon-mismatch labels, the dead-end navigations without return-scent) as the wayfinding-cue toolkit; the orientation-load management — the where-am-I problem: the documented disorientation costs (the lost-in-hyperspace findings from hypertext research transferred to dashboard hierarchies — the re-orientation working-memory tax after navigation: rebuilding the context model consumes the capacity saved by the destination), with the orientation-support patterns (the persistent-context anchors — the always-visible location indicators, the transition-continuity animations preserving the spatial mental model — the course-2 motion-continuity applied to navigation, the overview-map patterns — the miniaturized global view with position highlight); the navigation-structure load — the architecture effects: the breadth-depth trade-off quantified (the documented menu-structure findings: the optimal breadth at each level minimizing total navigation cost — the wide-shallow advantage for load with the scan-cost ceiling), the structure-consistency requirement (the same navigation grammar across the system — the automated wayfinding schema), and the path-frequency alignment (the common-task paths as one-interaction routes, the rare paths tolerating depth — the frequency-weighted architecture) as the structure-load engineering; the search-and-filter load — the query interface: the search-as-navigation pattern (the direct-access alternative to hierarchy traversal with the vocabulary-matching requirement — the synonym and typo tolerance as scent), the filter-state visibility (the active-filter display preventing the forgotten-filter confusion — the state-amnesia load), and the query-result-orientation (the result-to-source context links — the finding-within-context patterns) as the query-load management; the cross-tool navigation — the ecosystem wayfinding: the multi-dashboard and system navigation (the portal-hierarchy scent design, the cross-system deep-links preserving context, the tab-and-window management load — the browser-level orientation costs) with the destination-consistency standard (the same metric looking and behaving the same across tools — the cross-system schema coherence) as the ecosystem-load discipline; the interruption-and-resumption load — the return navigation: the documented resumption costs (the interruption-recovery research: re-finding position and state after diversion — the attention-residue effect), with the resumption-support patterns (the session-state persistence, the return-to-last-position defaults, the change-since-last-visit summaries — the streaming-course-13 connection, the bookmark and annotation personalization) as the interrupted-user load relief; the mobile-and-small-screen navigation — the constrained wayfinding: the viewport-limited orientation (the scroll-position-as-navigation problem, the collapsed-hierarchy patterns — the drawer and bottom-sheet navigation with the context-loss trade-offs, the thumb-reach interaction-cost geography) as the small-screen load adaptation; the foraging-measurement practice — the navigation evidence: the path-analysis telemetry (the actual navigation sequences versus designed paths — the revealed-foraging data, the dead-end and backtrack rates as the scent-failure metrics), the task-time decomposition (the navigation-fraction of total task time — the wayfinding-cost quantification), and the disorientation-event tracking (the rapid-back-navigation and search-after-navigation patterns as the lost-user signals) as the foraging-evidence system; the navigation anti-patterns — the failure catalog: the scent-free-iconography (the symbol-only navigation requiring learned-decoder rings — the expert-only wayfinding), the context-destroying navigation (the full-page transitions losing orientation — the teleportation failure), the filter-amnesia (invisible active filters corrupting comprehension — the hidden-state load), and the hierarchy-first-default (forcing navigation for the most common task — the zero-interaction-value violation from section 9) as the wayfinding-hygiene rules; and the foraging deliverable — the scent-rich, orientation-preserving, resumption-supporting navigation-load architecture.
