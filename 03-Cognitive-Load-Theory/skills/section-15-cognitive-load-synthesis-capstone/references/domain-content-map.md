# Domain Content Map — Synthesis and Capstone: The Load-Balanced Dashboard System

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module
development workflow. Verify all factual claims and numbers against the
authoritative sources before publishing (Phase 2 evidence base); flag
anything disputed rather than repeating it.

## Absorbed capabilities this module must produce
1. Execute the complete load-engineering cycle from task-audience analysis through three-load audit, architecture redesign, interaction-session design, measurement planning, and documentation.
2. Apply load-economics accounting (cost-in-load versus value-in-decision per element) achieving the informed-without-overwhelming-or-fatiguing standard.
3. Integrate grouping, preattentive, IA, latency, accessibility, EDA, narrative, and executive disciplines around the working-memory bottleneck, prevent canonical failures (quantity fixation, expertise reversal, disclosure mazes, interruption floods, unmeasured claims) through the effect-toolkit and audit systems, and uphold capacity-as-trust ethics with inclusive defaults and germane-respect climbing toward organizational load governance.

## Unit 1 — Unit 1

**Scope:** Prepares expert integration: the consolidated framework — the memory-architecture model (sensory-working-long-term systems with the four-slot bottleneck and dual channels), the three-load accounting (intrinsic-extraneous-germane classification and budgeting), the capacity mechanics (chunking, working-set analysis, externalization), the effect toolkits (contiguity, modality, signaling, segmenting, pre-training, coherence, redundancy-judgment, expertise-reversal adaptation), the visual-memory specialization (comparison architecture, pattern chunks, interference management), the complexity management (density-structure-glanceability, hierarchy, metric governance), the temporal dimensions (progressive disclosure, navigation foraging, session fatigue), the interaction economics (feedback, animation, manipulation load-balance), the expertise adaptation (spectrum-serving architecture), and the measurement system (triangulated load assessment, telemetry proxies, fatigue protocols) as one load-engineering discipline; the capstone workflow — the master arc: task-and-audience analysis (the decision tasks, working-set requirements, and expertise distribution), the load-audit of the current or planned design (the element-by-element three-type classification, the interactivity mapping, the chunk-count verification), the load-architecture redesign (the hierarchy-and-disclosure sequencing, the externalization and comparison-support installation, the effect-toolkit application with expertise-layered scaffolds), the interaction-and-session design (the feedback responsiveness, animation budgets, fatigue-aware pacing and alert economies), the measurement plan (the triangulated validation protocol with baselines and telemetry), and the documentation (the load-budget record with decision rationale) as the complete professional cycle; the load-economics principle — the integration insight: every display element as a line-item in the viewer's attention economy (the cost-in-load versus value-in-decision accounting — the section-1 attention-tax ethic operationalized), with the mastery criterion: the load-balanced dashboard where the viewer's finite capacity flows to the data's meaning rather than the display's friction — the informed-without-overwhelming-or-fatiguing source standard achieved as engineered outcome; cross-course integration — the curriculum position: Gestalt grouping (course 1) supplying the chunk-binding structures that make density affordable, preattentive channels (course 2) carrying the glance-tier extraction that pre-loads working memory, information architecture (course 7) extending load management to navigation-scale structures, latency engineering (course 8) delivering the interaction-responsiveness budgets, accessibility (course 9) setting the inclusive capacity-variance floor, EDA (course 11) ensuring the data complexity is real before the load is spent representing it, scrollytelling (course 13) sequencing load through narrative time, and executive communication (course 15) applying the glance-load discipline at the highest-stakes altitude; case synthesis — the worked exemplars (the operations-dashboard rescue from everything-visible to tiered-disclosure with detection-time and workload evidence, the analyst-workbench expertise-layered redesign with fading scaffolds, the executive-summary load-minimization preserving decision-necessary intrinsic complexity, the 24/7 monitoring wall fatigue-architecture with alert-economy governance) decomposed through the capstone workflow; failure post-mortems — the canonical errors (quantity-fixation stripping information while interactivity load persists, expertise-reversal single-design failures, disclosure-mazes burying critical data, interruption-flood session fatigue, unmeasured load claims from designer self-report) with the prevention systems from sections 3-14; the maturity model — stage one (load literacy — seeing the three types in existing displays), stage two (deliberate load architecture in own designs with working-set analysis), stage three (measured load systems with triangulated validation and expertise adaptation), stage four (load governance — organizational standards, audit cadences, and attention-economy culture) as the capability roadmap; the ethics position — the professional standard: the viewer's capacity as a trust held by the designer (the load-honesty audit — what does each element cost and earn, the inclusive-capacity default — designing for the low-span, fatigued, and assistive-technology viewer as the floor, the germane-respect — preserving productive effort rather than eliminating all thought) as the load-engineering ethics; and the capstone — a complete load-balanced dashboard system: select a real dense-display context with mixed expertise audience, run the task-working-set and three-load audit, redesign the load architecture (hierarchy, disclosure, externalization, effects, interaction budgets, fatigue pacing, expertise layers), specify the triangulated measurement plan with baselines and telemetry, and deliver the system with load-budget documentation, validation protocol, and governance recommendations.
