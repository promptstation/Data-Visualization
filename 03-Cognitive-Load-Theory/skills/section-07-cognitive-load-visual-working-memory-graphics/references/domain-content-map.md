## Absorbed capabilities this module must produce
1. Engineer chart reading around visuospatial working-memory limits using graphical-object chunking (grouping as capacity architecture).
2. Optimize comparison through alignment-proximity design and the externalization principle (reference lines, ghosts, computed deltas, pinning tools).
3. Select low-decoding-load encodings per the accuracy-as-load hierarchy with pattern-chunk elevation (shape-preserving ratios, named clusters).
4. Manage visual interference (similar-shape confusion, binding errors, change-detection failures) through discriminability and stability discipline, accommodate visual-memory variance with externalize-everything defaults.
5. Measure hold-load through recall probes, distance-comparison tests, and dual-task protocols.

## Unit 1 — Unit 1

**Scope:** Specializes the capacity science to visual material: the visuospatial-sketchpad domain — the visual buffer: the working-memory subsystem holding visual forms and spatial arrangements (the documented visual versus spatial dissociation — the shape-holding and location-holding partially separate resources), its refresh mechanisms (the eye-movement cycling — the saccade-back rehearsal, the mental-rotation and transformation costs) and its decay profile as the buffer specification for chart reading; the graphical-object chunk — the visual unit: the research on what counts as one item in visual working memory for graphics (the documented findings: grouped marks held as single objects — the Gestalt-binding capacity effect, the object-based storage — the bar-with-label-with-value as one chunk when bound, the feature-versus-object capacity distinctions) making grouping architecture a capacity architecture; the comparison-in-memory problem — the core dashboard task: the cross-element comparison mechanics (the two-series-hold-and-difference computation, the current-versus-previous evaluation, the multi-panel pattern matching) with the documented comparison costs (the precision degradation with held-item count from section 4, the saccade-distance effects — the far-apart comparisons costing re-encoding, the memory-versus-perception trade-off: comparisons done by looking — the externalized approach — outperforming comparisons done by holding) establishing the alignment-and-proximity comparison design imperative; the externalization principle — the display-as-memory: the systematic strategy of moving holds into the display (the reference lines replacing threshold memory, the ghost-series and prior-period overlays replacing baseline memory, the computed-difference and delta-callouts replacing mental arithmetic, the persistent-selection and pinning tools replacing held-comparisons, the annotation-restatement replacing value memory) as the dominant load-reduction pattern for analytical dashboards; the visual-difficulty factors — the encoding load: the documented decoding costs by visual form (the angle-and-slope judgment difficulty, the area-and-volume estimation errors, the non-aligned-scale comparison costs — the Cleveland-McGill hierarchy read as a load ranking: the accurate-fast encodings are also the low-load encodings), the transformation-load cases (the log-scale reading, the normalized-versus-absolute dual readings, the inverted-axis conventions) requiring schema support or avoidance as the encoding-load map; the pattern-hold capacity — the gestalt-chunk advantage: the trend-shape and cluster-pattern memory (the documented superior retention of meaning-loaded patterns over element lists — the shape-of-the-curve memory, the exception-location memory as compact chunks), with the design enablement (the shape-preserving aspect ratios preventing trend-distortion, the cluster-emphasis annotations naming the patterns — the pattern-labeling chunk-elevation) as the memory-optimizing encoding; the visual-conflict phenomena — the interference cases: the documented visual-working-memory interference (the similar-shape confusion in held items, the location-binding errors under load — the wrong-value-wrong-position swaps, the change-detection failures for held-versus-current comparison — the flicker-task analogs) with the design responses (the discriminable-encoding separation, the position-stability discipline — the reordering animations' binding-cost awareness, the explicit-change-marking removing the hold-and-compare requirement) as the interference management; the multi-view integration load — the cross-panel memory: the coordinated-view comparison costs (the cross-panel value holds, the linked-highlight relief — the selection-propagation externalizing the cross-view binding, the aligned-axis scaffold — the shared-scale position-comparison replacing value-memory) with the panel-count capacity limits (the documented multi-panel comparison degradation — the small-multiple scan strategies as the capacity workaround: sequential single-panel reads against a remembered template) as the multi-view load architecture; the individual visual-memory variance — the audience spread: the documented visual-working-memory capacity differences (the VWM-span individual variation, the field-dependence and visualization-literacy modulation, the aphantasia consideration — the mental-imagery variance affecting externalization dependence) with the conservative-design default (externalize everything — the low-VWM accommodation benefiting all) as the inclusive-capacity practice; the measurement of visual-hold load — the assessment practice: the change-detection and recall probes for displays (the post-glance element-recall as the chunk-capacity measure, the comparison-accuracy-by-distance testing, the dual-task interference protocols — the secondary-task degradation revealing primary-load) with the design-variant application (the externalization interventions measured against hold-heavy baselines) as the visual-memory evidence loop; and the visual-memory deliverable — the externalized, pattern-chunked, interference-managed comparison architecture.
