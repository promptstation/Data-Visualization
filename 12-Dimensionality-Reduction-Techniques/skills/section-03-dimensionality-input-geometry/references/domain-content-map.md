## Absorbed capabilities this module must produce
1. Engineer embedding inputs through preprocessing pipelines (cleaning-first doctrine with missing-outlier strategies, scaling-normalization systems with method interactions, transformation decisions for skew and composition, feature-space construction awareness).
2. Build distance-similarity inputs (metric-selection discipline with domain measures and method compatibility, affinity-kernel-kNN construction, high-dimensional pathology mitigations, ANN acceleration at scale, documentation obligations), master neighbor-graph foundations (kNN anatomy with k semantics and connectivity diagnostics, weighting schemes from binary through fuzzy membership, geodesic path distances with landmark approximations, local-linearity assumptions with violation diagnostics, neighbor-quality assessment).
3. Adapt to data types (numeric defaults, Gower-mixed-categorical strategies, sequence-graph-node contexts, pretrained image-text embeddings with anisotropy awareness, sparse-data handling).
4. Run preprocessing experiments (variant-comparison protocols, ablation testing, known-structure and domain-marker validation, reporting standards, garbage-in symptom recognition), and avoid raw-data embedding, scale blindness, metric autopilot, k-arbitrariness, hubness unawareness, imputation blindness, distance opacity, and single-pipeline trust failures.
