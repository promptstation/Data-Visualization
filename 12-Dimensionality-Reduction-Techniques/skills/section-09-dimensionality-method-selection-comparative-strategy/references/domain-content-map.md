# Domain Content Map — Method Selection and Comparative Strategy: Choosing the Right Projection

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module

## Absorbed capabilities this module must produce
1. Select reduction methods through decision frameworks (question-first routing with structure-type mapping, data-condition assessment inputs, constraint inventories across computation-interpretability-out-of-sample-reproducibility, rationale documentation), navigate the method-family matrix (linear positioning with PCA-MDS-random-projection niches, manifold family Isomap-LLE-spectral contexts, stochastic neighbor t-SNE-UMAP strength-weakness profiles, emerging densMAP-deep-triad options, comparison dimensions across preservation-computation-parameter-stability spectra).
2. Execute scenario playbooks (quick-overview, cluster-discovery, gradient-trajectory, outlier-anomaly, comparison-benchmarking, production-deployment patterns), compose hybrid strategies (baseline-then-refine sequences, multi-method consensus with disagreement diagnosis, sequential pipelines, view compositions with cumulative-distortion honesty), ground decisions empirically (published benchmark landscape with transferability caution, domain evidence, local calibration protocols, evidence integration and re-evaluation triggers), and avoid monoculture, novelty chasing, baseline skipping, disagreement avoidance, benchmark blindness, composition opacity, scenario mismatch, and rationale silence failures.
