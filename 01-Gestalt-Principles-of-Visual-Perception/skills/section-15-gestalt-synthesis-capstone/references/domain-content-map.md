## Absorbed capabilities this module must produce
1. Execute the complete perception-engineering cycle from task analysis through grouping planning, composition, failure audit, validation, and documentation, orchestrate grouping cues fluently using the measured strength hierarchy with reinforcement and deliberate-violation judgment.
2. Integrate preattentive, load, rendering, IA, accessibility, geometry, EDA, and communication disciplines around the grouping foundation, prevent canonical errors through hygiene systems and evidence culture, and deliver perception-engineered visualizations with cue-maps, validation records, and honest-accessible-inclusive standards climbing toward perceptual-system design maturity.

## Unit 1 — Unit 1

**Scope:** Prepares expert integration: the consolidated framework — the whole-thesis and organization problem (perception as constructive inference), the classical laws (proximity, similarity, continuation, closure, figure-ground, Pragnanz), the modern canon (common region, connectedness, symmetry, parallelism, convexity, common fate with the measured strength hierarchy), the dynamic layer (motion grouping, animated continuity, change detection), the search science (pop-out versus serial, the anomaly-detection modes), the application systems (chart-form grouping, layout composition, carrier channels), the failure hygiene (accidental patterns, illusions, artifacts, honesty), the validation methods (eye-tracking, experiments, rapid tests, telemetry), and the practice workflow (audits, critique, design systems) as one perceptual-engineering discipline; the capstone workflow — the master arc: data and task analysis (what patterns and anomalies must the viewer find — the search-mode requirements), grouping-structure planning (the intended-group hierarchy with cue allocation from the strength table), composition execution (chart forms, layout, carriers engineered per sections 9-11), failure audit (the hygiene checklist from section 12), validation (the evidence tier matched to stakes from section 13), and documentation (the cue-map and decision-evidence record) as the complete professional cycle; the cue-mastery thesis — the integration insight: expert practice as fluent cue orchestration (knowing which law to spend on which grouping, how cues compete and combine, when to reinforce and when to deliberately violate — the section-6 hierarchy and section-12 honesty internalized into fast design judgment) making the laws a playing technique rather than a reference list; cross-course integration — the curriculum position: preattentive attributes (course 2) as the salience layer riding on grouping structure, cognitive load (course 3) as the capacity budget grouping serves, the rendering APIs (courses 4-5) as the implementation surfaces where grouping decisions become pixels, IA and hierarchy (course 7) as the navigation-scale grouping, accessibility (course 9) as the redundant-carrier requirement, linear algebra (course 10) as the geometry underlying continuation and projection, EDA (course 11) as the data-truth verification before visual-trust, and executive communication (course 15) as the first-parse-decides-the-room stakes; case synthesis — the worked exemplars (the dashboard regrouping rescue — the panel-soup to hierarchy transformation with audit trail, the anomaly-detection display engineering both search modes, the responsive layout preserving grouping grammar across breakpoints, the multi-view coordinated system as one perceptual whole) decomposed through the capstone workflow; failure post-mortems — the canonical errors (checklist decoration without mechanism reasoning, accidental-grouping blindness, over-grouping chrome-glut, single-carrier fragility, designer-as-viewer validation, grouping-imposed deception) with the prevention systems from sections 12-14; the maturity model — stage one (law literacy and recognition), stage two (deliberate cue application in own compositions), stage three (audit and validation fluency with critique vocabulary), stage four (perceptual-system design — encoding grouping into design systems, teams, and evidence cultures) as the capability roadmap; the evidence-ethics position — the professional standard: grouping structure reflecting data structure honestly (the deception boundary), validated rather than assumed effects (the empirical discipline), and accessible-by-construction redundancy (the inclusive default) as the perceptual-engineering ethics; and the capstone — a complete perception-engineered visualization: select a real dataset and decision task, run the pattern-anomaly requirements analysis, plan the grouping hierarchy with explicit cue allocation, execute the composition (chart forms, layout, carriers) with documented decisions, run the failure audit and matched-tier validation with naive viewers, and deliver the case with cue-map, evidence record, and design-system recommendations.

## Unit 2 — Capstone integration

**Structure:** the learner takes a single problem in Gestalt perception through each unit's framework in sequence, producing a coherent deliverable that mirrors real professional documentation. Evaluation criteria: internal consistency across artifacts, evidence discipline, honest trade-off statements, and demonstrable use of each unit's framework.
