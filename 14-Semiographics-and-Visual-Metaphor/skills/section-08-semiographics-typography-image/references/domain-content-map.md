# Domain Content Map — Typography as Image: Letterforms, Text Graphics, and the Verbal-Visual Boundary

Read this during Phase 3 (architecture) and Phase 4 (writing) of the module
development workflow. Verify all factual claims and numbers against the
authoritative sources before publishing (Phase 2 evidence base); flag
anything disputed rather than repeating it.

## Absorbed capabilities this module must produce
1. Master the verbal-visual boundary through text's dual sign nature (symbolic content with iconographic form, dual-channel meaning, verbal-visual tradeoffs, typographic connotation and credibility research, text function hierarchy in visualization).
2. Apply functional typographic craft (typeface systems with numeric legibility requirements and superfamily strategies, modular scale and optical spacing architecture, contrast and color application, grid-aligned layout with alignment semantics, responsive fluid scaling and reflow strategies), wield expressive typography (scale-as-emphasis hero numbers, weight-width contrast systems, letterform manipulation with legibility tension, word-image hybrids including word cloud critique and calligrams, big-number design patterns with animation honesty, expressive restraint discipline), architect text-image integration (show-tell division with redundancy strategies, spatial integration patterns from inside through structure, reading-order engineering with accessibility alignment, systematic token governance with localization planning), and avoid connotation accidents, numeric illegibility, word cloud reliance, expression over legibility, redundancy waste, reading-order chaos, and localization blindness failures.
