## Absorbed capabilities this module must produce
1. Engineer animation performance against sustained-frame budgets with jank-visibility-amplification awareness, master composited fast paths (transform-opacity mechanics, property-cost hierarchy with FLIP for layout motion, will-change lifecycle, SVG-attribute exclusions, compositor verification).
2. Build rAF-driven JavaScript animation (delta-based interpolation, centralized loops, library cost profiles, precomputation-allocation discipline, element-count chunking and motion LOD) selecting JS only for data-driven-physics-morphing-choreography necessities.
3. Optimize data-visualization transitions (mark-count cost models, axis-tick caching and deferred declutter, aggregate-sample-cross-fade strategies for large data, interruption efficiency, selective object constancy), engineer scroll-narrative motion (compositor scroll-timelines, intersection-triggered activation, pinned-choreography budgets, transform parallax with vestibular restraint, reduced-motion narrative parity), govern ambient micro-animations (composited spinners, transform-based expansions, hover accumulation limits, visibility-based suspension).
4. Validate through frame-cadence monitoring, CI motion benchmarks, field jank telemetry, perceptual smoothness-comprehension correlation, and accessibility verification, prevent layout-property-JS-overuse-unbounded-permanent-promotion-input-contention-scroll-thrash-decorative-accumulation anti-patterns, and architect motion systems through performance-profiled tokens, component libraries, context budgets, triple review, and progressive device-adaptive enhancement.
