## Absorbed capabilities this module must produce
1. Engineer for device-network heterogeneity through fleet-reality analysis (device-class taxonomies, mobile tile-based-GPU-thermal-memory characteristics, webview variance, performance-equity-as-inclusion principle).
2. Detect capability via renderer-memory-connection probing, runtime benchmark classification, feature-detection fallback chains, and user-preference integration.
3. Build adaptive-quality systems (resolution-DPR scaling, effect-LOD cascades, frame-update-rate adaptation, content prioritization, hysteresis-switched transitions with honest reduced-mode communication).
4. Manage touch-interaction latency (tap-delay elimination, compositor scroll freedom, hover-absence alternatives, keyboard-viewport handling, finger-occlusion tolerances), engineer for network variance (connection profiles, payload economy, offline service-worker strategies with staleness honesty, request economy, Save-Data modes), govern battery-thermal costs (render-on-demand, wakeup consolidation, radio-efficient batching, thermal-state proactive adaptation, energy telemetry).
5. Validate through real-device testing, throttled profiles matching field distributions, mobile audits with lab-field gap awareness, fleet-segmented RUM, and tier-specific CI regression checks, prevent flagship-assumption-layout-squeeze-always-on-polling-heavy-load-hover-dependency-thermal-equity-blindness anti-patterns.
6. Synthesize progressive-enhancement architectures with tiered experiences, degradation chains, mobile-first budget culture, and cross-context continuity.
