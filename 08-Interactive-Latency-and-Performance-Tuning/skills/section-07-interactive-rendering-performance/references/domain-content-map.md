3. Verify through stage-level profiling, diagnostic overlays, render benchmarks, CI regression guards, and field INP presentation-delay attribution, prevent thrash-cascade-paint-storm-layer-explosion-effect-overload-DOM-bloat anti-patterns, and track modern containment-view-transition-timeline API evolution.
