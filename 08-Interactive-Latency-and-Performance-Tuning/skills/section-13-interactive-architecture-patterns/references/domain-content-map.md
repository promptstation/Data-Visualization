## Absorbed capabilities this module must produce
1. Compose latency architectures from the offload-incremental-memory-scheduling pattern families selected by product class.
2. Design worker systems (topologies, RPC-serialization communication tiers, worker-resident and SharedArrayBuffer data models, OffscreenCanvas rendering splits, lifecycle warmup-recovery-budgets).
3. Build streaming pipelines (transport selection, progressive render orchestration with backpressure, live-data subscription-ring-buffer-resynchronization, delta-state consistency, freshness honesty), architect multi-layer caching (layer profiles and coordination, semantic keying with invalidation strategy selection, stale-while-revalidate triggers and bounds, intent-idle prefetching under budget governance, cache observability), orchestrate scheduling (priority tiers with postTask, idle portfolios, concurrency-cancellation-dedup control, unified cross-context budget arbitration).
4. Integrate with frameworks (concurrent-transition-deferred patterns, store granularity and optimistic state machines, memo-lazy boundaries, headless cores), drive architecture evolution through latency ADRs, measurement-driven sequencing, strangler migrations with rollback provisions, scale-trigger roadmaps, and end-to-end budget verification, prevent monolith-cache-incoherence-worker-thrash-no-backpressure-prefetch-storm-priority-inversion-fashion-frozen anti-patterns.
5. Apply reference architectures for analytic dashboards, large-data explorers, live monitoring, and narrative scrollytelling.
